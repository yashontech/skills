# Overused words

Use this skill whenever someone asks you to write or rewrite text: emails, posts, captions, reports, proposals, messages.

## The list

`references/overused-words.csv` holds 135 items with three columns: Type, Overused, Swap. Read the whole file before you write anything. The types are:

- **Word**: single words to avoid.
- **Expression**: phrases to avoid.
- **Construction**: sentence patterns to avoid.
- **Punctuation**: the em dash, which is never used.

## Rules

1. Don't use any item on the list in your own writing. This includes other forms of the same word, such as plurals and past tenses.
2. Never use an em dash. Use a comma, colon, full stop or brackets instead, and don't use a double hyphen as a stand-in.
3. Don't write "It's not X, it's Y" or "It isn't about X, it's about Y". Say what the thing is.
4. Use the swap from the list, or rewrite the sentence so it reads naturally. Never force in a stiff synonym.
5. Text the person quotes or pastes for reference can keep its own wording.
6. Match the person's spelling (UK or US).

## Before you show the draft

1. Scan the draft against every item on the list.
2. Fix each slip.
3. Scan again, and only show the draft once nothing on the list remains.
4. End with one short line: "Checked against the overused-words list." If you fixed anything, name the slips in a few words.

## Changing the list

The list is a plain spreadsheet file. Delete a row to allow that word again, or add a row to ban a new one.
